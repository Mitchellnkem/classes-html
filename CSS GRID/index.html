CSS GRID LAYOUT

The Grid Layout Module offers a grid-based layout system for the web with rows and columns.

The Grid Layout Module makes it easy to design complex and responsive web-pages without any complex float or positioning.

GRID VS. FLEXBOX

CSS Grid is used for two-dimensional layout, with rows and columns.

CSS Flexbox is used for one-dimensional layout, either in a row or a column.
